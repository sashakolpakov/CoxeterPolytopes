families, retained compiled editions, concise dimension-bound source and
local upload package. [`arxiv/SUBMISSION.md`](../arxiv/SUBMISSION.md) selects
the source to use for each submission.

typesetting and sampled visual-review receipts. `right_angled_sharp/`
records the matching refreshed PDF build. Generated upload ZIPs and checksums live only in
ignored `dist/`; each current PDF is beside its source in `arxiv/`.

This manuscript artifact index is separate from the research-data release.
No bulk research asset has been uploaded, and the existing bulk-data
manifest and uploader are unchanged.
