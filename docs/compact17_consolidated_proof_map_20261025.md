The finite forest algorithm lists rank partitions and all spherical
irreducibles, retaining unbounded ordinary dihedral parameters symbolically.
It discards an entry only using a proved same-vector inequality. Finitely
many partitions and type choices prove termination; spherical classification,
actual-defect compatibility and spectator-uniform bounds establish coverage.
The result is a necessary cover, never a list of realized polytopes.

any arithmetic-table execution and the geometric consumer. Historical
