## Statement

Fix any strict interior point of a hypothetical compact Coxeter polytope
of dimension20 and any vertex farthest from it. Its ENTIRE finite vertex
forest must belong to the following necessary list:

| Dominant component | Entire remaining forest |
| --- | --- |
| A16 | OLD I2(7)/NEW isolated3 defect plus one ordinary irreducible T2 |
| A18 | OLD I2(7)/NEW isolated3 defect |
| A19 | One isolated short A1 of type I |
| A20 | None |
| B20 | None |
| D20 | None |

Here T2 is I2(m), m>=3. An ordinary old I2(7) without the actual
isolated opposite wall is not the typed defect in the table.
Arithmeticity is not assumed in this first statement.

For a hypothetical compact arithmetic FIRST-TYPE Coxeter polytope of
dimension18, over EVERY actual admissible ground field, the analogous
ENTIRE farthest-vertex forest must belong to this list:

| Dominant component | Entire remaining forest |
| --- | --- |
| A17 | One isolated short A1 of type I |
| A18 | None |
| B17 | One isolated short A1 of type I |
| B18 | None |
| D17 | One isolated short A1 of type I |
| D18 | None |

These are six necessary families in each class, not existence claims,
finite enumerations of actual polytopes, or assertions that a retained
family has passed every other possible obstruction. The statement holds
for the chosen farthest vertex; it does not make every vertex farthest.
