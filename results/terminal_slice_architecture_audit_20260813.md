# Terminal-slice audit: AGCat field queues versus Record 31

## Verdict

No field-by-dimension slice over `Q(sqrt(2))` or
`Q(2*cos(2*pi/7))` in dimensions 22--29 is presently close to an
exhaustive terminal classification.  The smallest such slice is

```text
Q(sqrt(2)), H22, native rank 23,
```

but even its first universal frame alphabet is already too large for the
current packet architecture, and none of the later universal manifests
exists.  The next terminal theorem should therefore be a global theorem for
one explicitly presented host (the current silver `Lambda22` nonreflectivity
route), not a purported field-wide AGCat exhaustion.

If that host theorem fails audit, the next most realistic terminal queue is
the compact `H9/14` Record-31 whole-shadow program.  It is vastly closer than
any high-rank field queue, although its `a=0` schedule means that it is not a
one-day closure merely because most of `a=1` is done.

The host route has now passed its production and independent hostile audits.
For

```text
M = <-(sqrt(2)-1)> + Lambda22
```

the full integral reflection subgroup has infinite index in the ambient
arithmetic orthogonal group, and its complete reflection chamber in `H22`
has infinite hyperbolic volume.  The independent audit regenerates, rather
than merely trusts, the complete separating-mirror necessary superset through
`H<=150`: 58 controls, 18 retained levels, 72 retained types, and seven
nonnegative threats, all seven excluded exactly.  This is a terminal theorem
for one whole arithmetic host, not field-wide nonexistence over
`Q(sqrt(2))`.

## What the AGCat layer actually proves

The real-framed projective quadric--polar-hyperplane carrier is faithful and
has exact return on its image.  It is nevertheless a tautological algebraic
encoding: the quadric recovers the quadratic form, polarity recovers the
facet-normal lines, and the real orientation recovers the original
half-spaces.  It supplies no independent emptiness or dimension obstruction.

There are genuine finiteness theorems in the dependency chain:

1. ABSW/Nikulin give unconditional finiteness of maximal arithmetic
   reflection groups.
2. The bounded connected-frame lemma supplies `m` independent walls with
   Cartan two-cycles below `62^2` at the selected place.
3. Integral closed cycles, diagonal-gauge reconstruction, Burnside, and the
   conductor sandwich prove finiteness of native lattice classes for fixed
   `(field, rank)`.

The repository's reconstructed fixed-data proof is mathematically more than
an encoding theorem.  But its computational consequence is presently
overstated whenever it is called a completed *decision procedure*.
Finiteness of the possible witnesses does not by itself provide the missing
manifests, and an ordinary Vinberg run has no finite stopping signal on a
nonreflective over-enumerated host.  The bounded-frame lemma applies to a
host already known to be reflective and finite-covolume; the reverse packet
enumeration necessarily contains formal representations and lattices that do
not have that property.  Thus `run Vinberg on every retained host` is not a
terminal algorithm unless every nonreflective row also receives an
independent finite nonreflectivity certificate.

Accordingly the sound implication is

```text
exact arrangement + external geometry + arithmetic
    => finitely many genuine maximal/reflective hosts,
```

not

```text
AGCat => an already enumerable finite list => emptiness is decidable now.
```

## Smallest high-rank field slice: exact debt

For `Q(sqrt(2))`, an independent exact enumeration of

```text
b in Z[sqrt(2)],
0 <= sigma_0(b) < 62^2,
0 <= sigma_1(b) < 4
```

contains **5,437** independent-frame two-cycle values.  Removing the sole
subparallel non-Coxeter value `2-sqrt(2)` leaves the exact Coxeter pair
alphabet

```text
0, 1, 2, 3, 2+sqrt(2), and 5,431 dotted products: 5,436 total.
```

Rank 23 has `binomial(23,2)=253` pair slots.  The unfiltered labelled upper
box is therefore `5436^253`, a 946-digit number (about `10^945.03`).  This is
not a runtime estimate--cycle and inertia propagation can prune it
drastically--but it proves that the current small-rank Cartesian packet
compiler cannot simply be scaled to this slice.

The exact missing universal stages for this one smallest slice are:

1. connected rank-23 graph augmentation and complete compatible cycle
   packets for cycle lengths 2 through 23;
2. a `Z[sqrt(2)]` prime-ideal/ideal-class gauge, rather than the existing
   rational-prime backend;
3. reconstruction and canonicalization of every symmetrizable admissible
   reflection representation;
4. full-order saturation, conductor computation, and enumeration of every
   stable lattice between the conductor bounds;
5. one complete full-host classification per lattice, with a finite
   certificate both for reflective termination and for nonreflectivity;
6. a canonical terminal survivor list and an emptiness proof.

The current universal counts after the pair alphabet are all zero:

| manifest | complete count |
|---|---:|
| connected rank-23 cycle-packet manifest | 0 |
| ideal-gauge/reflection-representation manifest | 0 |
| order/conductor/stable-lattice manifest | 0 |
| complete full-host transcripts | 0 |
| terminal empty-set certificate | 0 |

`cartan_packets.py` is a `Q`-only, rank-at-most-eight, finite-box simplex
prototype.  The golden modules materialize one pair box and selected local
three/four-node tranches, not a high-rank join.  The numerous silver and
cubic-seven search modules are fixed-host bounded Vinberg screens.  None is
the missing field-wide order/conductor compiler.

The cubic-seven slice is still less attractive.  It needs three-place signs,
ideal-valued gauges, and the same rank-23 global join and conductor stages;
the present cubic packet code covers only bounded equal-norm simplex/prism
discovery slices.  Its availability of exact cubic arithmetic does not turn
those bounded searches into a native-host census.

## Comparison with compact `H9/14` Record 31

Record 31 has a finite, explicit combinatorial queue and mature independent
replays.  Schedules `a=2,...,7` are closed.  In `a=1`:

- source 1 is strict-link impossible;
- sources 0, 3, 4, and 5 are closed;
- source 2 has exactly six canonical matrix-root classes;
- root classes 1, 2, and 3 are closed;
- root class 4 has 17 depth-two classes; 1--8 were frozen before this audit,
  and classes 9 and 11 completed normally here with zero **ridge-valid**
  targets.  Class 9 had no pure 120-facet target; class 11 had 13 pure
  120-facet targets, all rejected by the ridge condition.  Class 10 was
  interrupted without an archive when resources were redirected to the
  silver `Lambda22` terminal proof;
- root classes 5 and 6 remain;
- independent-incidence coverage gaps remain for sources 2, 3, and 4.

The `a=0` schedule is still a full missing branch.  Hence closing `a=1`
would be a real schedule theorem but not yet the Record-31 whole-shadow
theorem.  Even so, its remaining state is concrete and partitioned, unlike
the high-rank AGCat queue, whose first rank-wide packet list does not exist.

## Hard recommendation

1. Treat the now-audited silver `Lambda22` global nonreflectivity theorem as
   the terminal result of this cycle.  It closes one whole arithmetic host
   rather than extending a height prefix.  The independent hostile replay
   returns `PASS_GLOBAL_NONREFLECTIVITY`; the combined relevant suite passes
   28 tests.
2. Continue Record-31 source-2 root classes 4--6, independently replay the
   source gaps, aggregate `a=1`, then build the `a=0` completion census.
3. Do not spend the next search cycle on a field-wide
   `Q(sqrt(2))`/cubic-seven AGCat enumeration.  First implement and validate a
   general-field ideal-gauge and order/conductor backend at small rank, plus a
   finite nonreflectivity-certificate interface.  Without those, calling the
   high-rank finite set a practical decision queue is misleading.

This verdict does not weaken the global finiteness theorem.  It separates a
valid existential finiteness result from an unimplemented terminal
classification and redirects computation to queues that can actually produce
existence or nonexistence theorems.
