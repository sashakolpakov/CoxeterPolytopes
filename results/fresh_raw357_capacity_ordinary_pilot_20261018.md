## Complete relative reduction

A first marker fixes all nodes of its ordered active components. Each
active component of a second marker either equals a particular component
of the first, with a recorded node permutation, or lies in a previously
unused target component. Unused equal-type components can be permuted and
independently reflected by native target automorphisms fixing the first
marker. Thus a newly used component has no relative orientation invariant.
The second marker's roles stay ordered and its distinct whole components
stay distinct; they are never identified merely because their types agree.

Every relevant target forest is included. In each pointed domain, one
anchor is compared with all second-marker orientations of every coexisting
new and prior marker type. This gives11557 anchor comparisons. Complete
marker transitivity transports these comparisons to every possible first
marker. The signature records shared-role permutations; an additional
exact safeguard compares the entire canonically numbered contacted-union
Gram, all four missing covectors, both pairs of positive heights and the
omitted products. Every repeated signature must give identical data.

Passive forest factors may differ across target forests. They are
orthogonal and have zero missing-wall contacts, so they cannot affect
these cross products. This does not permit forgetting their rank or
multiplicity when deriving capacities. The reduction uses actual rank13
targets throughout, with no claim that an oversized host represents all
possible equality patterns.

## Conservative capacities of the new marker types

Write an oriented A2 component as its ordered endpoint pair u. For an
ordered pair(u,v), the four transformations

    (u,v), (v,reverse(u)), (reverse(u),reverse(v)), (reverse(v),u)

form one orientation class. The exact relative results say that two outer
A2 pairs can coexist only when they belong to this same four-element
class or use disjoint components. Partially overlapping distinct pairs
are excluded. This is a relation on distinct native keys; no orientation
is collapsed into an extra occurrence charge.

For type A, equal outer-pair classes can coexist with any H4 role. Disjoint
outer pairs can coexist only when their H4 role is the same. A clique with
two different H4 roles must therefore use one common outer pair; otherwise
all pairs form a matching in the b available A2 components. Its capacity
is exactly

    cap(A) = 4 max(h4, floor(b/2)).

For type B, every clique fixes one A1 and one H3 role. Its outer A2 pairs
form a matching, with four compatible native orientations per pair, so

    cap(B) = 4 floor(b/2).

For type C, every clique fixes one oriented I2(5) and one oriented central
A2 role. The outer pairs form a matching on the remaining b−1 A2 components:

    cap(C) = 4 floor((b−1)/2).

These upper arguments use the complete relative-rule partition. The
certificate also records a literal clique attaining each formula in
every target and checks every pair in each witness against the exact
retained relative cases. Sharpness is for the conservative compatibility
graph, not simultaneous physical realization.

Type C excludes both A and B. A and B may coexist only on one common
four-orientation outer-pair class. A target containing both has b=2 and
h3=h4=1 by rank13, so their combined bound is4+4=8. Taking all branches,
including the absence of any one type, gives at most eight new markers
at a vertex. These new-only statements do not yet bound the weighted
sum of new markers, old markers and ordinary stars with one allowance.
