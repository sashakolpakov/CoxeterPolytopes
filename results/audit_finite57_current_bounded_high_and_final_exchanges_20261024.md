### Complete finite target domain

An unpaid selected component contains a marked path of length at least
nine, hence at least ten roots. A finite completion is therefore classical
A/B/D; exceptional finite types and unbounded rank-two dihedral types are
too small. An affine completion of order at least ten is likewise classical.
For a certified whole bound B<=17, enumerate **every** finite rank and
affine order between the displayed component size and B. Finite C has the
same Coxeter graph as B. This classification step needs no arithmeticity.

`embeddings` assigns an unused target node to one pattern node at each
step, checking every already assigned edge and nonedge. Its degree test is
only a necessary condition, not a degree equality. The search depth is
the finite pattern size, and every branch has finitely many candidates.
Thus it halts. Given an actual induced embedding, induction on assignment
depth shows that its next image is never pruned: it is unused, has at least
the pattern degree and satisfies all earlier labels. Hence every actual
completion's marked images occur. Emitted maps need not all be realizable.

Native physical angles are recovered by `4*g_ij^2/(g_ii*g_jj)` in the finite
map helpers; the values1 and2 encode labels3 and4. This is distinct from
the native combinatorial adjacency used to reconstruct the high unions.
The positive gauges are not treated as norm-two Gram matrices.

Some successor `validate_maps` functions check every **saved** map but do
not run the backtracking search again. Their assertions establish local
validity, distinctness and the declared marked union, conditional on the
inherited map list being complete. A total such as578 or168 cannot by
itself prove completeness. The producing search and its exact saved-set
identity remain a separate finite premise.
