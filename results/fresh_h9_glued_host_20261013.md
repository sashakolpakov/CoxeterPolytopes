# A conductor-sixteen arithmetic H9 host and eight constructive cuts

No compact or finite-volume H9 polytope was found. This round changes the arithmetic ground field, rather than increasing an old host's search bound. The new host yields a complete 14-wall bounded Coxeter prefix. A targeted search constructs eight additional mutually compatible mirrors, giving a 22-wall cone. The independent replay verifies every root, every pair, and a strict spacelike escape, so this cone still has infinite volume. The full reflection group remains unresolved.

Let

```
T = 2 cos(pi/8),        T^4 - 4T^2 + 2 = 0,
alpha = T - 1,         sqrt(2) = T^2 - 2,

F = [[ 2, -1,        0,  0],
     [-1,  2, -sqrt(2),  0],
     [ 0, -sqrt(2),  2, -1],
     [ 0,  0,       -1,  2]],

L = <-alpha> + F + F + <1>.
```

The field has discriminant 2048 and ring of integers `Z[T]`. The coefficient alpha has signatures `(+---)` and norm -1. The F4 block has leading principal minors `2,3,2,1`, so L has signature `(9,1)` at the distinguished embedding and is positive definite at the other three. In particular, the host has no nonzero isotropic vector over its ground field. A genuine cusp or affine subdiagram cannot occur in any strict Coxeter chamber built from its field-valued normals. A finite-volume completion here would be compact.

This admissible form cannot descend, even up to scalar similarity, to a proper subfield: indefinite real places of a scalar-extended form would occur in fibers of size at least two. Here there is only one. The sole quadratic subfield is `Q(sqrt(2))`; the earlier silver host has repeated indefinite places after extension, while the golden and cubic fields do not embed in this degree-four field. Thus this is a different arithmetic-field construction from the recent quadratic and cubic hosts. No worldwide classification or new finite-covolume group claim is made.

The [structural certificate](fresh_h9_glued_host_20261013_structure.json) gives exact field and norm-alphabet checks. The Minkowski bound is `sqrt(18) < 5`. The unique prime above 2 is principal, generated by T, and 3 is inert; hence every ideal class has a principal representative. Four conjugates of `T-1` realize all 16 unit signatures. Since the unit group modulo squares has order 16, every totally positive unit is a square. PARI independently returned discriminant 2048, class number one, and the integral basis `[1,T,T^2-2,T^3-3T]`, a unimodular transform of the power basis.

The Gram matrix is unimodular. A primitive integral reflection normal therefore has norm dividing 2. Since 2 is a fourth power of the unique prime above it, a complete necessary pool of totally positive norm classes is

```
1,       2+T,       T^2,       2/(2+T)=2T^2-T^3,       2.
```

Their field norms are `1,2,4,8,16`. This is a full candidate pool, not a claim that every class occurs. Primitivity is checked by rejecting normals wholly divisible by T. No candidate class is silently omitted. The full dominant zero-height census finds exactly two norm-two F4 orbits per block and the scalar norm-one direction. The zero chamber is `F4 x F4 x A1`, with 98 oriented primitive roots and nine simple walls; no mixed extra zero-height orbit survives the complete enumeration.

```
    = 4(a+2c)^2 + 8(b+3d)^2 + 8c^2 + 8d^2
```

gives a finite integral alphabet, filtered by exact inequalities in all four embeddings. Dominant F4 covectors are enumerated with Schur bounds.
