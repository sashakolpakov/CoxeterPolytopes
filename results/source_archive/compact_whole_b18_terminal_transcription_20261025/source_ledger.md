## Scope and reader route

diagram is B18, in compact hyperbolic dimension eighteen. It is not an
arbitrary-spectator B18 component theorem. It does not prove a dimension
bound by itself or assert that a necessary forest is realizable.

The proof order is geometric, rather than chronological numerical increments:

1. Actual B18 unit roots, one original farthest vector and all-wall pressure.
2. Ordinary prefix inventory; both exceptional B2 roles at old16.

6. Near-three/own-six branch: the same short-white table, actual head
   native gap, positive finite projections and one supercritical scalar seal.
7. No-left branch: actual common/distinct-cap recognition and one shared
   local A16+dihedral lemma, followed by the normalized-endpoint local-A18
   consumer for the final common3/3 case.
8. Exhaustive terminal conjunction at the SAME original vertex.

The original x is never replaced during an original reference computation.
At a neighboring q the same z defines a new local vector and a derived
comparison factor. All summed orthogonal energies refer to that one q.

future negative core or compactness-forbidden null; unknown original wall
signs are checked termwise. No arbitrary face is called Coxeter.
