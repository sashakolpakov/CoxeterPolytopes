## Why the two guard defects are removed

The sole mathematical changes to `bind` remove all unmarked spectator
types from the literal forest, constrain every A13 paying role to the
same-component near-end images(0,11)/(1,12), and reject every affected
same-component D13 canonical image(0,11)/(0,12).

Consequently:

1. A displayed but unsealed A1 cannot finance a positive Boolean guard.
   No unmarked component is credited at all. This removes G0-F2 without
   assuming unmarked whole-component seals or manufacturing padding.

2. The unused rank-capacity subtraction has been removed. Any affected
   D13 image refuses the actual332 domain even when its chosen payment
   is only a half, so an unsealed A2 cannot dismiss the possibility of
   growing into a rank15 witness. This removes G0-F1 without a stronger
   all-displayed-whole premise.

3. The A13 near-end images have ordinary unit value in the pinned
   current table; they are different from the guarded endpoint pair
   (0,12). The condition is imposed on the COMPLETE independently
   reconstructed canonical image set. A guarded A13 endpoint cannot
   pass by presenting only a convenient saved image.

4. For every other accepted same/cross marked role, the literal forest
   contains only the actual whole paying components. The current
   finite/context clauses have no additional negative override except
   the explicitly excluded D13 role. Every omitted positive Boolean
   override increases its ordinary value, and the contextual cross
   additions are nonnegative. Thus the computed ordinary value is a
   lower for every extension by arbitrary other actual components.
   The source-specific wholeness of PAYING components remains the
   necessary geometric premise; arbitrary spectator wholeness does not.

The code compares that lower against each original chosen payment.
If a fixed output actually needs an unmarked positive guard, or has
an excluded D13/A13 image, it fails. Such a refusal would be preserved
as a newly exposed binding obligation, rather than silently financed.
