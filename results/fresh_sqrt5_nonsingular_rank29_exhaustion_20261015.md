## Why31 nodes is a proof boundary

The inherited arithmetic compact dimension bound is29; see the
[arithmetic scope report](arithmetic_dimension_bounds_and_effective_high_dimension_search.md).
This run concerns only possible counterexamples in dimensions28 or29.
A quadrilateral two-face of a compact simple Coxeter polytope in dimension
`d` has `d−2` common white facets and four side facets. Its full Gram matrix
therefore has `d+2` nodes, rank `d+1`, one negative direction and one linear
relation. In particular it has at most31 nodes. This is a dimension-specific
logical restriction, not an experimental cutoff or an all-rank theorem.

A31-node nonsingular Lorentz core has rank31 and cannot fit ambient rank30.
A31-node singular core can itself be a dimension29 star and is retained as
a weight obligation; no further white node fits. A literal31-node member
of the frozen subdivision families was checked against this boundary: its
inertia is `(29,1,1)` and its remaining spectator rank is zero.

## Complete continuation and stopping choices

At each smaller core the inherited complete profile generator enumerates
all nonzero contacts of one new white node, with labels2,3,4,5,6,10. Its
finite alphabet follows the ground-field restriction. All four new corner
diagrams must be spherical. A marked distance at most two already gives
the baseline payment; the persistent entire-H4 payment is also retained.
Any final weight rule must retain those payments.

Every remaining profile is tested for its exact field, physical and
conjugate inertia, and inherited linear relations. The arithmetic reuses
the frozen reviewed Fraction implementation over `Q(sqrt(5))`. It is not a
new independent field implementation. We deliberately omit the expensive
search for affine subsets and the search for old paid subcores. Omitting
such rejection tests only enlarges the necessary set.

Every core already contains a negative vector. Its radical in a Lorentz
realization must therefore consist of actual linear relations: the
orthogonal complement of that negative vector is positive definite.
Consequently an inherited relation must extend to every added root, and
more than one independent relation cannot fit a full quadrilateral star's
single relation. A nonzero nonnegative relation is impossible because a
strict interior point pairs negatively with every outward simple root.
The checker records these rejection witnesses explicitly.

If any external white node touches the core, one such node is a complete
enumerated one-white profile. Further white nodes can be ordered by their
first contact with the growing core. A chain cannot evade the search by
starting with a root orthogonal to the present core: start with the first
root that actually touches it. Components wholly orthogonal to the core
are spectators.

If no outside white touches a nonsingular core, the full Gram matrix is a
block sum of that core and a positive-definite white Gram matrix. It remains
nonsingular and cannot be a quadrilateral star. Such a core is rejected.
If the core is singular, the no-further-contact choice is instead a weight
obligation. **Every processed singular core is exported**, even if it has
accepted touching children or was paid by an older rule. The export stores
all four complete corner forests, the marked connected-component pair
orbits, existingA1 counts and the remaining spectator rank budget separately
for dimensions28/29. No payment is asserted. Additional orthogonal white
components may change a forest-sensitive weight, so their allowed ranks
must be considered by the eventual weighting certificate.

## Durable enumeration and review scope

Exact invariant buckets accelerate isomorphism search. Within each bucket
the frozen independent backtracking checker considers every opposite-pair
preserving black permutation and compatible white bijection; every retained
map is checked on all labels. It is not a heuristic graph hash.

An entire core is evaluated before writing. Its result, every child and
literal map, and the next-core cursor commit in one synchronized SQLite
transaction. Initialization is atomic too. Resource guards pause only
between whole-core transactions and leave every pending state. Resume
requires the same source manifest. Saved replay reconstructs every seed
and processed domain, checks every child map and all reachability, and
verifies the database bytes and pending records.

The compact-search agent's narrow source audit accepted the31-node boundary,
the all-singular stopping obligations and the orthogonal-spectator logic.
It did not replay the queue or independently reconstruct the profile
arithmetic. The initial100-core saved replay is producer verification.

This queue covers only descendants of the311 finite-label nonsingular
first extensions. Dotted seeds and the other already-separated families
have their own certificates. Even an empty queue would not prove the
desired dimension bound without paying every singular obligation and
combining all relevant families. Necessary principal stars are not asserted
to have actual compact-quadrilateral realizations.
