## Literal function and exact currency

Library lines 145--172 implement all finite same-component replacements,
the special B17 rule, and the feature-depth/short-fork rules for rank at
least eighteen. The graph numbering and feature predicates agree with
the appendix. Lines 178--250 apply broad cross rows first and the later
replacements afterward. In particular A1/D10 has zero at the center and
the two short-leaf halves; the corrected source has no center unit.

Lines 253--316 delete the marked components before counting whole
witnesses. Same-type components remain distinct copies. Boolean presence,
the union in the first A1/D5 guard, the second joint A1/D5 increment,
and the two-A2 multiplicity are kept separately. The two A1/D5 increments
sum to one under the joint guard without repeating the first term when
A11 is also present. The symbolic context coefficients match pair counts;
for example four marked-node pairs times 9/32 times `choose(a2,2)` gives
`36*a2*(a2-1)` in sixty-fourths.

Driver `base` uses the explicitly preliminary B13 restoration.
`value(final=True)` removes one unit per B13 separately and adds the
three final rank-15 guards. Thus its final value matches the current
ordinary B13 zero rather than counting that change twice. Fractions,
integer multiples and their divisions remain exact throughout; no floating
currency conversion appears. The A17 barred base is lower by 22
sixty-fourths, and the driver consistently restores `+22*count(A17)`
where that representative is used as an upper bound.

The affine table and feature rule agree with the printed order convention.
Order two is handled as the single A1 affine factor without constructing
a two-vertex cycle. The small exceptional orders are explicit; their
diagram classification and geometric multiplicities remain external inputs.

## Domains, coverage and the direction of each assertion

The finite type domain is exactly the 177 printed payment types of rank
at most 58: A, B, D, the named exceptional types, and one symbolic class
for every I2(m), m>=5. Its equality with B2 concerns these payments only.
The native classification, rather than enumeration of infinitely many
labels, justifies that class. The cross shortcut's host set contains every
possible nonzero ordinary host in the literal table; all omitted pairs
are consequently zero. The representative map retains the separate A12
and D12 fibers and the distinguished A17.

`domination` (188--206) asserts equality of literal guarded bases with
the saved base export, but only **inequality** of actual cross-plus-
allowance costs against barred costs. It does not assert equality of
all legacy actual cross coefficients. `residual_zero` (209--215) separately
checks residual/residual interactions and residual versus fixed A1/A2.

`context_rows` (218--262) covers every marked pair and every submultiset
of each listed Boolean witness stratum, retaining the duplicate A1 count
where two witnesses are needed. It correctly tests the same-component
increment families and the A1/A2/A3 disjunction for D14. Its small
stratum checks are not a replacement for the universal symbolic
multiplicity argument.

`final_forests` (265--279) checks the eight **previously costly**
B13/D13 plus three-rank15 forests and the six positive-guard forests.
The identities 58=13+3*15=28+2*15=12+16+2*15 exhaust the final
rank-15-triggered cases. The unconditional preliminary B13 restoration
also changes other forests; the eight returned `negative_forests` must
not be described as every forest affected by that ordinary-table change.
Its saved-old-costly-list equality is the additional inherited boundary.

The affine shards (282--292) partition orders 2--58 and compute the
maximum family sum divided by **order**, comparing it to envelope key
`order-1`. They bind the literal costs to the frozen envelopes. They
do not establish ideal profile counts, local terminal receipts or the
geometric factor-fiber inequality.

`domain` (175--185) recursively covers every nonnegative rank9--17
count vector with total at most 58, every A12 split, and every rank5
count fitting the remainder. `coarse_index` joins precisely this complete
3298-key set to the saved expanded rows, then joins all saved
`upper+22*A17>377*64` keys to the 39 coupled classes. Cardinality and
set equality together exclude duplicate or omitted class keys.

The coarse shards (311--341) reconstruct literal barred residual weights.
For each saved table they check base value zero and every admissible
transition `v[n] >= v[n-r]+w[r]`, at every n through 58. Rank one
is present, so all nonnegative ranks are reachable. Induction gives a
valid upper bound; equality, optimal predecessors and a fresh maximizing
recurrence are unnecessary for this claim. The full reservation formulas
are bounded by the saved row bounds. Their mathematical applicability
still uses the separately reviewed actual-count removal/reservation
coverage argument; the code does not prove that argument.

The four fiber shards (344--374) generate every combinations-with-
replacement product over the actual-type fibers of each fixed
representative multiset. Sorting and set equality, together with row
counts, establish complete fixed-fiber coverage without treating
different component orders as different forests. Each table's allowed
residual type set and every listed coefficient are checked exactly.
Duplicate table keys are rejected. Complete required flag coverage,
saved Bellman upper validity, fixed cost, explicit w1/w2 coefficients
and the complete explicit-option comparison are **not proved here**.
An attaining forest's full literal equality does not fill those gaps.

The conditional shards (377--398) cover exactly the 759 fixed choices
with rank9 present and rank5 count positive. They bind all literal
barred weights, including the unconditional extra 40 per rank5 on the
A1 item, and all displayed reservation upper bounds. Their saved
residual-table upper validity is expressly inherited; these shards do
not recheck its transitions. They establish an upper inequality, not
attainment of the relaxed bound by an actual forest.

## Schema, parsing and resources

I compared the accessed fields with the producers' frozen output
definitions: the coarse table key includes `key`, `fixed_A5_count`,
`exclude2`; fixed rows carry the separate A12 split; coupled classes
use `counts,k5,a12,residual_rank,rows`; each flag table carries
`key,types,weights,values,last`. Conditional tables are stored in
the producer's False/True order, which the driver uses. The source
does not conflate the earlier representative fields with actual-fiber
fields or the native `maximum` rational strings with scaled integers.

Only the independent literal library and the two bounded adapters are
imported. I read their top-level definitions: they do not execute or
import the native mathematical producers. The read-only mmap adapters
retain 40 MiB file and 24 MiB selected-value/item limits; array values
are decoded one item at a time. Path objects reject duplicate selected
keys, but nested decoded JSON uses ordinary `json.loads`; skipped
syntax and arbitrary nested duplicates are not fully validated. The
frozen file hashes are therefore a substantive input boundary, as the
adapter documentation already says. This is not an arbitrary-JSON
validation claim or a general heap-allocation guarantee.

All mathematical loops are finite at the stated rank: nine recursion
levels for fixed counts, bounded count intervals, finite fiber products,
finite flags and ranks, and at most 58-node graph traversals. Caches
have a finite type-pair domain. No maximizing recurrence or native
worker is called. Actual runtime and peak RSS remain unmeasured here.

The supported launch route is the assertion-safe public entry, through
the unchanged bounded runner, owner check, already-held shared lock,
one thread, 50-second inner alarm and 59-second/1 GiB outer watchdog,
with unchanged admission/floor gates. The driver's own `assert __debug__`
is not a standalone defense against direct optimized Python; the public
entry supplies that defense. Do not document a raw `python -O` route or
treat owner/lock checks as a substitute for the watchdog. No gate is
relaxed by this source review.
